# WEBSITE-HERO-CANDIDATE-001：同舞台三幕与开放执行

## 目标与适用范围

对应[当前候选任务与用户要求](../../tasks/todo.md)中“B／C 按 Agent 归属模型 Logo”。仅覆盖本地 `/drafts/hero-open-story/` 的 B 微缩立体、C 二维角色候选，不替代[正式页面动画合同](work-animation-order.md)，不验证真实模型、兼容矩阵、员工创建或学习效果。候选是否采用仍待用户看稿。

## 前置条件

- 通过本地 HTTP 服务访问候选及正式 CTA 目标；不能直接打开文件 URL。
- 使用真实浏览器；时间线可控时钟以实际 elapsed 为准，生命周期使用真实时钟。
- 桌面 1440×900、手机 390×844 验证时间线；布局另补 1920、1280、1024、768、320，分别模拟系统 light／dark。

## 覆盖与证据

2026-10-22 布局修复复验：原版 1440×700／1280×720 首屏超高 23px、1024×768 过早单列的回归先失败；修正整个右栏的高度预算与单双栏断点后，16 组首屏／边界布局、42 组综合布局、6 组生命周期、6 个无 JS 场景和 8 个真实导航通过，页面错误为空。本轮未改动画模型，未重跑下面所列的 96 个完整时间线点。

前一轮按 Agent 归属 Logo 版验证：2 幅 SVG XML、12001 个模型采样、96 个实际 elapsed 状态、42 组布局、4 组生命周期、4 个无 JS 场景和 8 个真实导航；页面错误为空。新增不可变模型归属、研究 Agent 无编码 CLI 配置、SVG 图像实际解码、侧面标签不缩小、Logo 与角色／相邻标识互不遮挡检查，保留完整学习职责与方法历史回归。此处 verified 仅指本地候选展示行为，不表示方案已被采用或正式产品兼容性已验证。前版全局选择／切换语义已删除，其证据只在任务历史保留，不作为现行预期。

当前候选的执行结果和修复记录见[任务 Review](../../tasks/todo.md)。纯模型、浏览器时间线、布局及生命周期分别记录，不能以旧版成绩或模型通过替代本候选实际播放。验收脚本与截图为本地协作资产，未作为可提交自动化提供；跨环境仍须准备候选并按本页重放。
