# WEBSITE-HERO-LIFECYCLE-001：同一需求，从澄清到下一版

## 目标与范围

历史草稿合同：2026-10-22 用户确认方向并要求迁入正式官网后，本页保留本地 `/drafts/hero-b-lifecycle/` 独立中文候选的审计证据，当前正式组件与中英文验收以[正式动画合同](work-animation-order.md)为准。对应[任务记录](../../tasks/todo.md)；[原 B／C 研究故事](hero-open-story.md)继续作对照，不混用成绩。REQ-014、岗位、模型与反馈均为虚构示意，不验证真实员工配置、模型执行、发布系统、学习效果或兼容矩阵。

## 前置条件

- 通过 HTTP 服务打开新候选，正式 CTA 与原 B／C 路径可访问。
- 使用真实浏览器；动画测试的可控时钟以页面实际 elapsed 为准，交互生命周期使用真实时钟。
- 桌面和手机分别观看首轮 50 秒及至少两个 21 秒关注循环；布局补短屏、901／900 断点和 320px 窄屏。

## 覆盖与证据

2026-10-22 Logo 实体工位版复验：原始素材检查验证人像＋三品牌共 4 个内嵌图像、2 个 CLI Logo 字节不变，无 Bot、独立模型名或重复职责标签。12001 个模型采样、96 个桌面／手机实际 elapsed 状态、22 组布局、3 个无 JS 场景、3 组真实时钟生命周期及 5 个实际导航全部通过，errors／failures 为空。新增交接途中三工位不互遮、整体同尺度移动、只含一个品牌图像与职责短名的检查，已看关键帧联系图和工位 4×细节。前版 7 图像的证据只属于初版，不作为现行期望。

2026-10-22 初版执行：12001 个模型采样、SVG XML／原始素材字节核对、96 个桌面／手机实际 elapsed 状态、22 组布局、3 个无 JS 场景、3 组真实时钟生命周期及 5 个真实导航通过，页面错误为空。时间线包括两个完整关注循环和镜头／翻阅峰值；已看整页、三幕中间帧与物件 4×细节。生命周期以真实运行／冻结状态建立观测基线，不用固定等待时间假定 IO 已回调，也不把固定时间内的速率当成恢复合同。

执行详情与修复过程记录于[任务 Review](../../tasks/todo.md)。纯模型、实际时间线、跨尺寸、交互生命周期、无 JS 与导航分开记账；用户随后确认此方向并要求正式迁移，候选成绩仍不代替正式组件验收。自动化和截图为本地协作资产，不作为可提交测试映射；其他环境按本页准备历史候选并重放。
