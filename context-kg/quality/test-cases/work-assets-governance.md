# WEBSITE-CONTENT-002：工作、资产与治理

## 目标与范围

落实[工作、资产与治理内容合同](../../research/work-assets-governance-outline.md)。只验证官网内容、导出、链接与展示，不验证产品后台策略、模型费用或生产权限。

适用范围对账（2026-10-27）：本页的三营销页／首屏布局描述只适用于保留的英文页与历史中文版本，不能作为中文商业V3的当前版式合同。正式迁移后的13页中文站、固定能力舞台和产品投影以[商业官网正式迁移与发布门禁](commercial-production-release.md)为准，其发布状态单独记录；本页的双语文档、旧URL、费用语义和只展示不证明后台策略的边界继续适用。

## 前置条件

已安装项目依赖；运行 `npm run build`，通过本地 HTTP 服务访问静态导出。保留中英文路径和原有文档地址。

## 自动化映射

- `node scripts/check-site-content.cjs`：24 篇双语文档、原 URL、分组、96 个文档链接、前后篇及费用状态／策略边界关键词。关键词存在不替代人工语义审查。
- `node scripts/check-hero-lifecycle.cjs`：正式生命周期的人为关口、AI 总结与修改采用、v1 历史和 v2 待验收；平台范围与产品边界仍须人工核对。
- `node scripts/check-marketing-browser.cjs`：正式路由的中英布局、无 JS、完整时间线、播放生命周期和导航；环境参数及边界见[动画用例](work-animation-order.md)。
- `node scripts/check-work-system.cjs`：旧平台关系模型历史回归，不证明当前首页挂载。
- `node scripts/check-product-story.cjs` 与 `node scripts/check-home-workflow.cjs`：原有动画纯模型。
- 浏览器本地证据由任务 Review 记录；截图查看是布局验证，不能证明生产治理生效。
