# WEBSITE-FLOW-001：工作动画的因果与归属

## 目标与范围

落实[官网页面职责与叙事](../../research/work-assets-governance-outline.md)；适用于中英文首页与 `/concept`。当前首屏为 B 微缩立体、Logo 实体工位与同一需求 REQ-014 的三幕生命周期，左侧保留平台定义，案例不替代整体价值。订单原生执行演示仍在 `#workflow`，完整员工培养仅在工作方式页；旧平台关系图退出挂载，历史纯模型回归保留。独立[生命周期草稿](hero-b-lifecycle.md)的成绩不替代正式组件验证。不验证真实资产发布、员工创建、模型调用或客户工作验收。

## 前置条件

- 官网已安装现有依赖，可运行 `npm run build`。
- 通过本地 HTTP 服务访问导出的 `out/`，不直接打开文件 URL。
- 普通动态偏好与减少动态分别运行；鼠标悬停不是暂停手段。

| 同一需求首轮 | 查看 0–50 秒的关键关口 | 7.5 秒确认范围、9 秒方案就绪后开发加入；验证发现重复提交并修正复验，23 秒验证、24 秒人验收、25.5 秒批准、26.5 秒发布。AI 总结后人实际补充权限角色，35.5 秒确认、36.5 秒采用、38 秒保留、39 秒引用到同需求 v2。先更新验收条件，再实现与验证；46 秒后仍待人验收 |
| 历史与查看循环 | 首轮后观察两个完整 21 秒循环，比较关键字段 | 50 秒后每幕 7 秒只转移查看重点，v1 发布快照及方法修订 0 不变，来源、方法原件和引用持续保留；v2 方法修订 1、未验收、未发布。不重播人确认、采用或发布，无常驻传输轨迹 |
| 首屏与案例 | 初始查看首屏，点击主 CTA 进入工作案例 | 订单演示在 `#workflow`，离屏冻结，滚入后开始；首屏离屏冻结；锚点标题不被导航遮挡；完整案例链接进入工作方式页 |
| 原图与可访问名称 | 键盘进入原图入口，打开后 Escape 关闭 | 原生正文不包在一个巨大链接内，内容可以正常阅读／选择；仅独立原图入口可点击，名称包含可见标签；关闭后恢复焦点，键盘 hold 不被意外解除 |
| 原生执行过程 | 从首轮推进到至少三个查看循环 | 计划逐项完成；已完成步骤产生记录，检查先于交付；结果保持待人工审阅；后续仅切换记录／检查／产物查看重点，完成数、记录和结果不重置 |
| 历史协作模型 | `storyFrame("overview", elapsed)`，观察首轮及后续两轮 | 交付逐项增加产物、依据、人工确认；保留交付标记跨轮。仅属保留模型回归，不作为当前首页挂载证据 |
| 员工培养 | `workflowFrame` 从 0 到 5，步长 .005；浏览器观察真实阶段与实时说明 | 开场无员工；记录先于 AI 方法候选，人实际修改“核对导出”为“按权限核对行数”，确认采用后才形成员工。配备就绪后接受新任务，成果返回后由人验收；中英实时说明与可见动作一致 |
| 页面归属 | 访问产品、工作方式、企业架构三页 | 首页为生命周期首屏、原生研发案例与培养截图、资产／治理累积机制；工作方式保留完整订单案例及唯一完整培养图，架构仍解释关系和边界，不改成厂商 Logo 墙 |
| 资产复用 | 首轮形成后跨越至少两次循环边界 | 来源、人确认、Skill、版本、复用标记和执行员工保持；新任务取得引用，不重播资产形成 |
| 使用与准入 | 保留 Run、Token 与费用状态，切换新 Task | 已记录消耗不重置或凭空增加；允许与拒绝互斥，模型禁用只改变新请求的决策 |
| 轨迹 | 对照传输卡和轨迹的透明度，检查流转前后及重启 | 培养与资产／治理传输路径和数据卡同步显隐，不成为常驻流光；静态结构关系可保留 |
| 播放边界 | 悬停一整轮，键盘聚焦后移开，滚动离屏 | 悬停继续；键盘聚焦暂停、移开恢复；离屏停止 |
| 静态回退 | 开启减少动态或禁用 JS | 显示静态完整关系与可读阶段说明，不倒放培养，不残留传输轨迹；手机无 JS 的培养图用完整六阶段文字回退，不机械缩放桌面图 |

## 自动化映射与边界

- [`node scripts/check-hero-lifecycle.cjs`](../../../scripts/check-hero-lifecycle.cjs)：正式生命周期 12001 样本、精确人工门禁、v1 历史／方法不变、v2 待验收、本地化和服务端场景／原 Logo 工位结构；实际挂载与布局另测。
- [`node scripts/check-marketing-browser.cjs`](../../../scripts/check-marketing-browser.cjs)：通过 `BASE_URL`、`PLAYWRIGHT_MODULE`、`CHROME_EXECUTABLE`、`ARTIFACT_DIR` 指定环境；覆盖正式双语路由的布局、无 JS、实际 elapsed 时间线、生命周期和导航。测试时钟在浏览器初始化脚本中控制，不依赖生产 seek 接口或本地草稿。
- [`node scripts/check-work-system.cjs`](../../../scripts/check-work-system.cjs)：旧平台关系模型的因果、传输窗口和结果保留，仅历史回归，不再证明首页挂载。
- [`node scripts/check-execution-preview.cjs`](../../../scripts/check-execution-preview.cjs)：原生执行模型的首轮与四次查看循环，完成及记录单调不减、检查先于交付、等待人工审阅；不把检查／查看循环称为再次执行。
- `node scripts/check-work-story.cjs`：7000 个正式三图模型采样，三轮累积、条件互斥、后续不重复形成或计量、英文读数完整性与负时间边界。
- `node scripts/check-product-story.cjs`：保留旧协作模型的 601 个位置回归；不将其当作新首页实际挂载证据。
- `node scripts/check-home-workflow.cjs`：1001 个培养模型位置、来源／确认／配备／任务／验收顺序。脚本名保留历史命名，培养图当前位于工作方式页。
- 浏览器复现：中英文，1440 与 390 真实播放；布局补充 1024 / 768 / 320；检查阶段0及最后阶段、循环起点、减少动态和无脚本。
- 模型通过不替代图形实际挂载、可见性、文字与资源加载检查；静态截图不证明完整自动轮播。
