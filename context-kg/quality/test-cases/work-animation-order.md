# WEBSITE-FLOW-001：工作动画的因果与归属

## 目标与范围

落实[官网页面职责与叙事](../../research/keynote-website-information-architecture.md)的两种动画合同；适用于中英文首页与 `/concept` 工作方式页。不验证实际产品员工创建、模型调用或客户工作验收。

## 前置条件

- 官网已安装现有依赖，可运行 `npm run build`。
- 通过本地 HTTP 服务访问导出的 `out/`，不直接打开文件 URL。
- 普通动态偏好与减少动态分别运行；鼠标悬停不是暂停手段。

## 参数组与预期

| 场景 | 输入与步骤 | 预期 |
| --- | --- | --- |
| 首页协作 | `overviewFrame` 从 0 到 3，步长 .005；浏览器观察四阶段与完整循环 | 同一工作依次交给协作者，执行后出现证据，返回人侧后才能验收；首屏 H1 不随播放变化 |
| 员工培养 | `workflowFrame` 从 0 到 5，步长 .005；浏览器观察六阶段 | 开场无员工；记录经验完整后整理方案；确认后形成员工；配备就绪后接受新任务；成果返回后验收 |
| 页面归属 | 访问产品、工作方式、企业架构三页 | 首页仅协作概览；工作方式页仅一份完整培养图及订单案例；架构页不重复培养图 |
| 轨迹 | 对照传输卡和轨迹的透明度，检查流转前后及重启 | 培养轨迹与数据卡同步，其他阶段不常驻；首页交接线路在验收前消失 |
| 播放边界 | 悬停一整轮，键盘聚焦后移开，滚动离屏 | 悬停继续；键盘聚焦暂停、移开恢复；离屏停止 |
| 静态回退 | 开启减少动态或禁用 JS | 显示完整静态结尾和可读阶段说明，不倒放培养，不残留传输轨迹 |

## 自动化映射与边界

- `node scripts/check-product-story.cjs`：601 个首页纯模型位置、超界 clamp、输出范围、委派／证据／验收顺序。
- `node scripts/check-home-workflow.cjs`：1001 个培养模型位置、来源／确认／配备／任务／验收顺序。脚本名保留历史命名，培养图当前位于工作方式页。
- 浏览器复现：中英文，1440 与 390 真实播放；布局补充 1024 / 768 / 320；检查阶段0及最后阶段、循环起点、减少动态和无脚本。
- 模型通过不替代图形实际挂载、可见性、文字与资源加载检查；静态截图不证明完整自动轮播。

## 覆盖状态与证据

2026-10-18：两条纯模型命令执行通过；Chrome 中四阶段协作、六阶段培养、自动循环、悬停、键盘、离屏、双语无脚本与减少动态检查通过。结构与完整交付结果见[Keynote 改版任务 Review](../../tasks/todo.md)。测试只证明官网叙事与展示，不证明产品业务结果。
