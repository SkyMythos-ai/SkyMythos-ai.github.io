在日常企业落地中，团队往往不需要从零拼装复杂工作流。以下整理了 SkyMythos 最常复用的**四类精选能力组合**以及覆盖企业 **8 大核心职能岗位**的快速落地对照表；如需查看分步实操样例，可直接前往[实践案例一至七](/zh/docs/practice-doc-processing)。

## 四类高频精选能力组合 [#four-curated-capability-bundles]

| 能力组合 | 核心构成 | 解决什么问题 | 典型参考案例 |
| --- | --- | --- | --- |
| **知识溯源问答与报告组合** | `SkyBot 项目` + `企业知识库` + `原文引用` | 让制度咨询、客户反馈归因与调研报告每一条结论都有发布版本原文可查 | [实践一](/zh/docs/practice-doc-processing) / [实践七](/zh/docs/practice-lark-knowledge) |
| **合规起草与专业分工组合** | `数字员工` + `权限隔离知识库` + `人工审批` | 将 HR、法务、财务标准模板固化给专业员工，严守最小权限与人工终审边界 | [实践二](/zh/docs/practice-compliance-writing) / [实践五](/zh/docs/practice-self-evolution) |
| **工程研发与门禁交付组合** | `个人开发机` + `Tasks` + `Flows` + `Unit Gate` | 从需求与仓库基线出发，在隔离 Sandbox 完成编码、单测门禁与 Git Diff 交付 | [实践六](/zh/docs/practice-git-delivery) |
| **周期汇总与自动推送组合** | `Automations` + `定时/事件触发` + `Run 追踪` | 替代每周手工搬运材料生成周报或巡检摘要，留存每次运行输入与费用记录 | [实践四](/zh/docs/practice-daily-briefing) |

## 企业 8 大核心岗位落地速查矩阵 [#eight-role-adoption-matrix]

对齐官网[岗位解决方案](/zh/solutions)，不同部门推荐按以下配置起步：

| 核心岗位 | 典型高频场景 | 推荐入口组合 | 必备前置能力与资料 | 关键人工把关节点 |
| --- | --- | --- | --- | --- |
| **HR 人力资源** | 制度问答、岗位 JD 起草、候选人评估纪要整理 | SkyBot 项目 + 知识库 + 数字员工 | 发布《员工手册》《招聘评分标准》至受权知识库 | 录用决策、薪酬沟通与对外 Offer 发送 |
| **财务（Finance）** | 报销合规初审、制度条款对照、月度差异说明起草 | 数字员工 + 知识库 + Automations | 发布《差旅与报销制度》；接入只读账单脱敏表 | 付款审批、正式财务报表签发与入账动作 |
| **法务（Legal）** | 合同条款比对清单、合规基线核对、风险批注摘要 | SkyBot 项目 + 知识库（严格权限隔离） | 建立独立权限隔离的法务知识库与标准合同范本 | 法律意见定稿、对外签署与风险豁免拍板 |
| **销售（Sales）** | 客户需求梳理、方案材料检索组装、跟进纪要汇总 | SkyBot + 企业知识库 + 飞书/Lark 连接器 | 同步最新脱敏产品白皮书、FAQ 与授权案例库 | 商业报价承诺、合同折扣与正式客户外发 |
| **市场与运营** | 反馈归因、活动复盘报告、周度内容排期辅助 | SkyBot 项目 + 数字员工 + Automations | 品牌规范文档、历史活动脱敏数据与渠道文案手册 | 公开渠道发布、投放预算调整与对外公告 |
| **产品（Product）** | 竞品与用户访谈整理、PRD 结构化草案、验收清单 | SkyBot 项目 + 知识库 + Tasks（看文档） | 产品历史决策记录、架构说明与设计系统规范 | 需求优先级排序、上线范围拍板与变更发布 |
| **软件研发** | 需求研发交付、单测补全、Code Review 初筛、排障 | 个人开发机 + Tasks + Flows/WorkNodes | 个人 Git 凭据、代码规范 Skill、测试门禁命令 | 架构变更审批、Git 代码合并与生产发布 |
| **IT 与管理** | 接入数据流评估、工单初诊、团队用量与成本审计 | 可观测性 + 团队/平台管理 + 连接器 | 网关目录、沙箱集群配置、企业 SSO（IdentityLink） | 成员权限开通/吊销、生产变更与模型出口批准 |
