**SkyMythos** 是面向企业私有化部署的 **AI-Native Harness** 工作平台。你可以使用自然语言描述工作目标，由 SkyMythos 结合团队知识、连接器工具与专业数字员工，在受控的隔离环境中规划并执行任务，交付带原文引用、代码变更与检查记录的可验收成果，并将确认后的经验沉淀为企业可复用的长期能力。

<Callout type="info" title="使用与评估提示">
  本手册覆盖从产品介绍、新手入门、全功能说明、实践案例到私有化部署运维的完整指南。不同企业部署环境的可用模型、连接器与运行配置以当前工作空间为准；尚未接入的企业团队可先[预约 POC](/zh/poc) 或查看[定价与授权说明](/zh/pricing)。
</Callout>

## 核心能力 [#core-capabilities]

- **自然语言与结构化意图交互**：通过清晰的目标、资料、交付物与边界描述发起工作，无需手写复杂脚本或反复拷贝背景。
- **受控规划与多阶段执行**：支持从即问即答的 SkyBot 对话，到围绕长期目标的 Project 协作，再到严格分阶段门禁的研发 Flow 编排。
- **代码与多格式文档处理**：支持读取与解析文本、Markdown、PDF、图片及代码仓库，产出文档报告、结构化数据摘要或可审查的 Git Diff。
- **工作空间与持久开发机操作**：每位研发成员拥有独立持久化的个人开发机，每个正式研发任务在隔离 Sandbox 内执行，文件与权限边界清晰。
- **多会话与后台任务并行**：支持同时推进多个 Project Thread、研发 Task 与定时自动化 Run，并在统一收件箱处理等待人工确认的事项。
- **结果交付与能力复利**：每项交付保留工具日志、原文引用与门禁检查证据；人工确认后的有效做法可提炼为数字员工技能与企业知识版本。

## 与传统 AI 对话的区别 [#difference-from-traditional-ai-chat]

| 对比维度 | 传统 AI 对话工具 | SkyMythos 企业工作平台 |
| --- | --- | --- |
| 能力边界 | 只能对话与提供文字建议 | 能在隔离环境读取仓库、运行命令并连接受权工具 |
| 上下文准备 | 每次手动复制粘贴文档和要求 | 按工作空间授权实时召回已发布知识，任务启动冻结规格 |
| 执行方式 | 单一长会话混杂讨论与修改 | 区分即时对话、项目协同、分阶段研发 Flow 与定时 Run |
| 交付标准 | 输出一段文本回复作为结束 | 交付带原文引用、Artifact 产物、Code Diff 与检查日志的成果 |
| 能力沉淀 | 有效方法随个人聊天记录散失 | 沉淀为待人工确认的数字员工技能提案与可追溯知识版本 |

## 认识工作界面 [#understand-the-workspace-ui]

登录 SkyMythos Web Console 后，工作台主要由四个协作区域组成（详情见[左侧导航栏与工作台布局](/zh/docs/workspace-guide)）：

| 界面区域 | 所在位置与核心功能 |
| --- | --- |
| 顶部工具与状态栏 | 切换当前 Workspace、查看个人开发机健康指示器、打开通知中心与切换中英文/明暗主题 |
| 左侧导航栏 | 一级模块入口（工作总览、收件箱、SkyBot、开发机、研发任务、自动化、数字员工、知识库、可观测性、市场、连接器、设置）及上下文侧栏 |
| 中央对话与工作区 | 承载对话消息流、项目任务创建表单、代码差异/产物明细或流程编排视图 |
| 右侧助手与结果区 | 呼出全局平台助手（Platform Assistant）辅助问答或起草提案，以及查看执行详情、文件上下文与交付产物 |
