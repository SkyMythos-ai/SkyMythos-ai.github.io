## 商业模式与两类合作路径 [#commercial-model-and-engagement-paths]

SkyMythos 面向企业客户提供**纯私有化部署**方案，当前合作分为两个阶段，均根据企业实际规模、接入工作面与集成范围单独评估报价（不提供无约束的公开自助试用或虚构阶梯标价）：

| 合作阶段 | 适用场景与范围 | 评估与报价方式 |
| --- | --- | --- |
| **场景试点验证（POC）** | 围绕 1–2 个真实部门或研发场景，在受控环境中按约定标准开展端到端验证 | 按试点范围、接入方式与支持周期单独评估报价 |
| **企业正式部署** | 在企业自有基础设施全栈交付，按团队席位授予年度使用许可 | 按授权团队席位规模、部署架构与集成服务单独报价 |

## 三项清晰的费用边界 [#three-clear-cost-boundaries]

1. **按团队席位年度授权**：许可费用对应实际使用 SkyMythos 工作台的团队成员席位规模，而非按普通对话次数售卖“积分包”。
2. **部署与企业集成服务**：涉及私有化集群规划、企业 SSO/IM 连接及定制适配的实施支持，按实际交付范围单独核定。
3. **自有模型费用独立结算**：SkyMythos 对接企业自有大模型或自选模型网关，底层大模型推理与向量化 Token 费用由企业与模型供应商独立结算，不包含隐形加价。

## 用量查看与成本归因路径 [#usage-and-cost-visibility]

在日常使用中，成员与管理员分别通过以下入口核对资源消耗：

- **个人与执行级视角（`可观测性 → 用量与成本`）**：成员可按模型与时间范围查看自己有权访问的 SkyBot Turn、研发 Task 与 Automation Run 的输入/输出 Token 及已登记计价模型的已知成本（[详情见可观测性](/zh/docs/observability)）。
- **团队管理视角（`团队设置 → 成员用量与成本分析`）**：`Workspace Admin` 可按团队成员维度审计工作空间内的活跃度与模型消费分布（[详情见团队与平台管理](/zh/docs/administration)）。

## 联系我们与获取企业支持 [#contact-and-enterprise-support]

- **预约 POC 试点评估**：前往[预约 POC](/zh/poc)，填写公司名称、关注场景与希望验证的目标。
- **企业项目与授权咨询**：前往[企业项目与报价咨询](/zh/poc?enquiry=enterprise#main-content)，与顾问沟通私有化部署架构、席位规划与商务报价。
- **技术问题协助**：反馈运行或部署异常前，请先对照[异常提示与故障排查说明](/zh/docs/troubleshooting)整理脱敏后的环境与复现清单，切勿在沟通材料中附带任何明文密钥或私有正文。
