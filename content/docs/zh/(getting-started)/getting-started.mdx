本指南面向已经取得工作空间访问权限的新成员。尚未接入的企业团队可先[申请 POC](/zh/poc) 规划评估环境。通过下面五个步骤，你可以在 15 分钟内完成第一项“有清晰验收标准”的工作。

## 开始前的最小准备清单 [#minimum-prerequisites]

在发起第一项工作前，请先核对以下三项条件已就绪：

1. **工作空间身份**：确认自己已登录目标 Workspace，并具备参与协作的角色权限（如 Member）。
2. **可用模型与凭据**：确认当前工作空间可见至少一个兼容模型；若平台要求个人密钥，请提前在连接配置中保存个人模型凭据（参见[模型网关、协议与个人凭据](/zh/docs/models-tools)）。
3. **所需资料与仓库权限**：涉及团队文档时，确认目标知识库已发布且可检索；涉及代码改动时，确认已绑定 Git 凭据并拥有对应仓库读取权限。

## 五步完成第一项可验收工作 [#five-steps-to-complete-your-first-work]

<Steps>
  <Step>
    ### 选择一个结果容易核验的小目标

    首次使用建议挑选“资料来源明确、边界清晰、容易判断对错”的小型任务，例如：基于一份已发布的反馈文档提炼三项优先改进建议，或为测试仓库某个接口补充空值校验。这有助于快速验证环境、授权与产物链路是否贯通。
  </Step>
  <Step>
    ### 按工作性质选择合适入口

    | 你的工作目标 | 推荐工作入口 | 首次发起核对重点 |
    | --- | --- | --- |
    | 围绕同一目标持续补充背景、组织文件并多轮协同 | [SkyBot 与项目协作](/zh/docs/projects) | 项目名称、共享目录、主会话与执行 Thread 区分 |
    | 基于代码仓库完成分阶段、带测试门禁的工程变更 | [研发任务（Tasks）](/zh/docs/tasks) | 需求正文、Repository、Base branch、Flow 与必填输入 |
    | 按定时或外部事件周期性重复执行固定流程 | [自动化编排](/zh/docs/automations) | 流程定义、运行环境、触发规则与每次 Run 结果 |

    以上入口服务于不同场景，无需机械地让同一个任务依次走完三个模块。
  </Step>
  <Step>
    ### 用“四要素结构”写清指令

    在发起工作前，写明**目标、授权资料、预期交付物、人工决策边界**四要素。直接复用以下模板并按实际内容替换：

    ```text
    目标：整理本周提供的客户反馈，归纳三项最紧急的体验改进建议。
    资料：仅检索我当前有权访问的《产品反馈汇总》知识库与接入说明。
    交付：每项建议写清问题描述、引用来源原文链接与建议验证方式。
    边界：仅形成待审阅报告，不修改生产配置，不对外发送任何通知。
    ```
  </Step>
  <Step>
    ### 在工作面追踪进度与人工介入

    发起后，在对应详情页关注输入接收状态、工具调用记录与阶段产物。如果系统弹出明确提问或动作审批请求（ActionApproval），先核对请求涉及的目标对象与操作影响，再点击同意或补充说明。

  </Step>
  <Step>
    ### 基于真实产物与原文完成验收

    运行结束后，依次核对四件事：产物文件能否正常打开、内容是否覆盖全部原始目标、引用的知识片段是否能在同一版本原文中核实、代码任务是否附带变更 Diff 与实际跑通的检查记录。
  </Step>
</Steps>

<Callout type="warn" title="安全与凭据使用规范">
  切勿在任务描述、聊天输入框或共享文档中直接粘贴明文 API Key、Token 或个人密码。所有模型密钥与第三方授权均应通过平台或个人配置入口加密保存。
</Callout>

## 新手常见疑问排查 [#common-first-use-issues]

- **下拉列表看不到模型或代码仓库**：前往个人连接与授权设置检查是否已完成对应网关或 Git OAuth 授权；页面请求异常时使用重试按钮，先区分“网络读取失败”与“确实无可用资源”。
- **结果偏离原始预期**：不要同时在多个会话或入口散落互相矛盾的补充要求；回到原工作上下文中，针对具体差异补充约束后继续推进。
- **想把这次的有效方法固定下来**：先确认产物本身已通过人工核验，再决定是否将经验沉淀至[数字员工](/zh/docs/employees)或发布到[企业知识库](/zh/docs/knowledge)。

完成初次体验后，建议继续阅读[工作台导航与全局助手](/zh/docs/workspace-guide)，全面熟悉界面各个区域的分工。
