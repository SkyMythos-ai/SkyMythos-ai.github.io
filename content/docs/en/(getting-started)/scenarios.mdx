SkyMythos supports everything from quick single-turn document analysis to multi-week software delivery and recurring automations. The tables below map common enterprise needs to platform capabilities.

## 1. Daily Office & Business Operations [#daily-office-and-business-ops]

Designed for HR, Finance, Legal, Sales, Marketing, Product, and Operations teams handling high-frequency knowledge and drafting work:

| Scenario | How SkyMythos Helps | Recommended Surface |
| --- | --- | --- |
| Customer Feedback Triage | Group sanitized multi-channel feedback and trace priorities back to published product specs | SkyBot Projects + Knowledge |
| Policy Q&A & Compliance Checks | Answer staff questions from handbooks and expense policies with exact revision citations | Published Knowledge + AI Employees |
| Contract & Memo Drafting | Draft structured agreements or HR notices from approved templates and list missing review items | AI Employees + Knowledge |
| Business & Variance Analysis | Summarize structured tables, flag anomalies, and highlight figures requiring human sign-off | SkyBot Chat / Automations |
| Sales Proposal Assembly | Search sanitized whitepapers, FAQs, and approved case studies to prepare tailored customer briefs | Knowledge + Lark/Feishu Connector |
| Weekly Operational Digests | Aggregate approved inputs on a schedule to draft reviewable weekly reports | Automations |

## 2. Software Engineering & Code Delivery [#software-engineering-delivery]

Built for software engineers, tech leads, and platform teams delivering auditable code changes in isolated sandboxes:

| Scenario | How SkyMythos Helps | Recommended Surface |
| --- | --- | --- |
| Feature Delivery from Specs | Start from requirements or Git issues, run understand/code/gate stages, and deliver Git diffs + MR summaries | Engineering Tasks + Flows |
| Unit Test & Validation Coverage | Add boundary validation and unit tests verified by deterministic Unit Gate commands | Engineering Tasks + Unit Gate |
| Automated Pre-Review Screening | Inspect branch diffs inside a sandbox against team coding conventions and produce review notes | WorkNode + Convention Skills |
| Persistent Cloud Coding | Work continuously inside a personal PVC-backed Dev Machine with Web Terminal and full toolchains | Personal Dev Machines |
| Incident & Bug Triage | Correlate error logs, observability traces, and source code to propose root-cause hypotheses | SkyBot + Observability |

## 3. Ongoing Project Collaboration [#ongoing-project-collaboration]

When an initiative spans multiple days, evolving inputs, and parallel sub-tasks:

- **Shared Working Directory**: Open multiple threads inside the same SkyBot Project to collaborate on shared specs or datasets without re-uploading files.
- **Sourced Project Memory**: Retain confirmed design decisions and constraints as sourced project memory so follow-up threads stay aligned.

## 4. Specialized AI Employees & Skill Reuse [#specialized-employees-and-skills]

- **Standardize Role Workflows**: Package prompts, models, and minimal tool scopes into [AI Employees](/docs/employees) so anyone on the team produces consistent outputs.
- **Controlled Experience Evolution**: Turn successful runs into reviewable improvement proposals and update employee definitions only after human approval.

## 5. Enterprise System Integration [#enterprise-system-integration]

- **Git Hosting**: Admins configure Git provider endpoints while members link personal Git tokens for authorized repository reads and diffs.
- **Lark / Feishu & Slack**: Enable enterprise SSO (`IdentityLink`) and import explicit Docx links into governed Knowledge Bases.
- **MCP Tool Servers**: Connect internal ticket systems, read-only databases, or dashboards through standardized MCP connectors with full trace logging.
