**SkyMythos** is an enterprise **AI-Native Harness** designed for private deployment. Describe your objective in plain language, and SkyMythos coordinates authorized team knowledge, connected enterprise tools, and specialized AI employees inside isolated execution environments—handing over source-cited reports, reviewable code diffs, and check logs while turning approved methods into reusable organizational assets.

<Callout type="info" title="Scope & Evaluation Notice">
  This documentation covers product overview, beginner quickstarts, full feature reference, hands-on practice cases, and Kubernetes operations. Available models, connectors, and runtimes depend on your active deployment. Teams evaluating enterprise onboarding can [request a POC](/poc) or review [Pricing & Licensing](/pricing).
</Callout>

## Core Capabilities [#core-capabilities]

- **Natural Language & Structured Intent**: Launch work by stating clear goals, authorized materials, deliverables, and human boundaries—without fragile glue scripts.
- **Governed Planning & Multi-Stage Execution**: Progress smoothly from instant SkyBot chats to persistent Projects and deterministic multi-stage engineering Flows.
- **Code & Multi-Format Document Handling**: Read and process text, Markdown, PDFs, images, and Git repositories to produce structured reports, summaries, or reviewable diffs.
- **Persistent Dev Machines & Isolated Sandboxes**: Give engineers a dedicated persistent machine backed by Kubernetes storage while running formal engineering Tasks in isolated per-task Sandboxes.
- **Concurrent Threads & Background Runs**: Run multiple Project threads, Tasks, and scheduled Automations in parallel while handling approvals centrally in your Inbox.
- **Verifiable Delivery & Compounding Capabilities**: Keep full tool traces, exact document citations, and Unit Gate logs—promoting only human-reviewed methods into AI employees and Knowledge releases.

## How SkyMythos Differs from Traditional AI Chat [#difference-from-traditional-ai-chat]

| Dimension | Traditional AI Chat | SkyMythos Enterprise Platform |
| --- | --- | --- |
| Execution Reach | Text suggestions inside a single chat box | Executes in isolated sandboxes with authorized repos and tools |
| Context Handling | Manual copy-paste on every new conversation | Real-time permission-checked knowledge recall and frozen TaskSpecs |
| Workflow Structure | One long thread mixing exploration and edits | Dedicated surfaces for Quick Chats, Projects, Flows, and Automations |
| Delivery Standard | Ends with an unverified text reply | Hands over Artifacts, source citations, Git diffs, and Unit Gate logs |
| Capability Retention | Useful prompts stay buried in personal history | Curated into reviewable AI employee proposals and versioned Knowledge |

## Understand the Workspace UI [#understand-the-workspace-ui]

Inside the SkyMythos Web Console, work happens across four coordinated zones (detailed in [Sidebar & Console Layout](/docs/workspace-guide)):

| UI Region | Location & Core Function |
| --- | --- |
| Top Bar & Status Strip | Switch active Workspaces, monitor Dev Machine service health, open notifications, and toggle language or Light/Dark theme |
| Left Navigation Rail | Switch top-level modules (Overview, Inbox, SkyBot, Dev Machines, Tasks, Automations, AI Employees, Knowledge, Observability, Marketplace, Connectors, Settings) and context sidebars |
| Main Workspace Canvas | Displays conversation threads, task creation drawers, code diffs, artifact details, or Flow editors |
| Right Assistant & Context Area | Toggle the global Platform Assistant for help or draft proposals, and inspect run context, files, and deliverables |
